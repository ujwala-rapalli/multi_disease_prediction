# multi_disease_prediction


Predict multiple diseases (Diabetes, Heart Disease, Parkinson's) using pre-trained ML models — fast, simple, and ready to test.

> ⚡ Quick snapshot: this repo includes pre-trained model files (`diabetes_model.sav`, `heart_disease_model.sav`, `parkinsons_model.sav`) and a prediction script (`prediction1.py`). See `requirements.txt` for dependencies.


---

## About
This project provides a small demo of multi-disease prediction using pre-trained machine learning models. The focus is on making predictions from clinical / feature inputs via a simple Python script.

---

## Features
- Predicts **Diabetes**, **Heart Disease**, and **Parkinson’s Disease** using three separate pre-trained models.  
- Simple single-file entrypoint to run predictions (`prediction1.py`).  
- Models saved as `.sav` (pickle / joblib style) and ready to load.
